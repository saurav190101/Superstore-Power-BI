
## Superstore Sales & Profit Dashboard


## Project Overview

This project analyzes sales and profitability trends for a retail superstore. Using data visualization and insights reporting, the dashboard highlights top-selling products, price-tier efficiency, and customer profitability across multiple years.

The goal of this dashboard is to provide actionable business insights for decision-makers, such as identifying profitable products, high-value customers, and category performance.
